# 클릭 브랜드 웹페이지

고민은 짧게, 선택은 시원하게.

이미지나 외부 라이브러리 없이 작동하는 한 장짜리 브랜드 소개 페이지입니다.

## GitHub에 업로드하기

1. ZIP 파일을 압축 해제합니다.
2. GitHub에서 새 저장소를 만들거나 사용할 저장소를 엽니다.
3. **Add file → Upload files**에서 `click-website` 폴더 안의 파일을 올립니다. `index.html`이 저장소 최상위에 오도록 올려 주세요.
4. **Commit changes**로 저장합니다.

## GitHub Pages로 공개하기

1. 저장소의 **Settings → Pages**를 엽니다.
2. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
3. 업로드한 브랜치(일반적으로 `main`)와 **/(root)**를 선택하고 **Save**를 누릅니다.
4. 배포가 끝나면 Pages 설정에 표시되는 웹주소로 접속합니다.

GitHub Pages의 사용 가능 여부는 계정 요금제와 저장소 공개 설정에 따라 달라질 수 있습니다. 공개 저장소에 올리는 내용은 누구나 볼 수 있습니다.

## 연락처 수정하기

`index.html`에서 `[직접 입력]`을 검색하여 실제 연락처와 연락 링크로 바꿔 주세요. 현재 연락 버튼은 연락처 안내를 펼치는 방식입니다.
